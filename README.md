# 跨国临床试验随机分组和揭盲控制台

源提示词摘要：研究中心按分层因素生成随机分组；药品管理员只见发药信息，研究角色正常情况下不可见治疗组；重复受试者和编号冲突被阻止；紧急揭盲需填写原因并形成不可删除审计记录，断网提交进入待处理队列。

## 技术栈

Nuxt 3、TypeScript、Element Plus、Pinia、Nuxt 路由、Axios、VueUse、VeeValidate、Zod、Vue I18n。

## 本地运行

```bash
npm install
npm run dev
```

开发端口：`62028`

## 可用流程

- 入组：机构、分层因素和受试者编号校验后，按中心 × 年龄分层做区组随机（每区组治疗组各半，区组满了才开新块），随机号与治疗组在入队时即固定。
- 防重复：入库前按受试者表和更早的待提交记录重新核对身份标识与受试者编号，冲突记录标记为冲突并追加审计，不写入受试者表。
- 角色隔离：药品管理员始终可见治疗组（发药），研究者和监察员仅在揭盲后可见。
- 安全审计：紧急揭盲要求原因，添加后只能追加，不能删除或改写。
- 离线队列：模拟离线提交进入待提交队列，随机号入队时固定保证离线顺序与审计一致，联网后由授权人员确认入库。
